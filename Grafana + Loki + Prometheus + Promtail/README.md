Доступ к Grafana: перейдите по адресу http://localhost:3000 (учетные данные по умолчанию: admin / admin).  
Источники данных: настройте подключения к Prometheus (http://prometheus:9090) и Loki (http://loki:3100) в разделе Connections → Data sources.  


	• Grafana: http://localhost:3000
	• Prometheus: http://localhost:9090
	• Loki (проверка готовности): http://localhost:3100/ready (должно вывести текст ready)
